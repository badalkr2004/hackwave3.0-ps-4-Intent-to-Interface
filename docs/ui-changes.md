# UI polish changes

- Progressive Why: panels stay quiet by default; a per-panel Why control opens score and evidence so explanation is opt-in.
- Global Show why is a labeled switch with a slim score strip (no filled green box) to keep the lens calm and scannable.
- Newsreader + Instrument Sans (self-hosted): editorial page title with a clean UI sans; no CDN fonts.
- Type scale tightened (title ~38px, panel 16 medium, body 14, secondary ≥13) for hierarchy without noise.
- Header: wordmark + workspace once; account actions live in an avatar menu so the chrome stays light.
- Intent bar as hero: taller field, `/` hint, stage copy inside the bar while composing.
- DiffRibbon: “N added · N unchanged” on the headline row instead of a vague “What changed” pill.
- Brand indigo vs status green/amber/red: accent no longer doubles as “healthy/success.”
- Warm flat paper background; panels hairline-bordered without stacked shadow.
- Tokenized panel S/M/L caps; pin/dismiss appear on hover/focus; thin scroll fade.
- Shared StatusBadge height/icon pattern; truncated lists open “+N more” detail dialogs.
- Usage trend: domain ticks, dashed baseline, hatched drop, release labels, end-point value.
- Bar charts: value labels, faint grid, no legend clutter.
- Layout: 8px rhythm, 24px gutters, 1440 max width, tighter chip-to-grid spacing.
- Skeletons match S/M/L geometry; empty/error states give a next step.
- Selection color, SVG favicon, document title follows headline; auth glow blobs removed.
